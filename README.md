# TP Organización Empresarial - Análisis de Ventas
Este trabajo consiste en un análisis básico de ventas realizado con Python.
Se utilizó un archivo CSV con datos de productos, cantidades y precios para calcular ventas totales y generar gráficos.
También se trabajó con herramientas de organización y control de versiones como GitHub, Git y Jira.

## Herramientas usadas:
- Python
- Pandas
- Matplotlib
- Git
- GitHub
- Jira
- Google Colab
- 
## Carpetas del proyecto
datos/
resultados/
scripts/

## Qué hace el proyecto
- Lee un archivo CSV de ventas
- Calcula ventas totales
- Genera un gráfico de ventas por producto
- Crea un archivo resumen con los resultados

## Cómo ejecutar el script
1. Clonar el repositorio
2. Abrir el proyecto en Google Colab o Python
3. Ejecutar el script de análisis de datos
4. El programa leerá el archivo CSV y generará:
   - un gráfico de ventas
   - un archivo resumen con los resultados
   
## Archivos generados
- ventas.csv

- resumen.txt
